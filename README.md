# Scarp
A dynamic programming language implementation made in Java and C following the [crafting interpreters](https://craftinginterpreters.com) book.

## Implementations
| Version | Status | Documentation |
| :--- | :--- | :--- |
| **Java** | Complete & Stable | [Java README](./java/README.md) |
| **C** | Complete & Stable | [C README](./c/README.md) |

### Java Version
This version is ready for use. It contains the tree-walk interpreter pipeline, including the scanner, parser, resolver, and runtime environment.

### C Version
This version is ready for use. It contains a bytecode VM with a scanner, single-pass parser/compiler, and runtime.

Both the C and Java version are compatible with each other except for some feature differences. Read the [C README](./c/README.md) to know more.
